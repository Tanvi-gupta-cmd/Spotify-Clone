🎧 Spotify Clone

A modern and responsive Spotify Clone built using frontend technologies. This project replicates the core UI and basic functionality of Spotify, allowing users to browse, play, and control music.

🚀 Features

🎵 Play / Pause songs

⏭ Next / Previous track controls

📃 Dynamic song list

🎨 Clean and responsive UI

🔊 Seekbar and volume control

💻 Works on desktop & mobile devices

🛠️ Tech Stack

HTML5 – Structure

CSS3 – Styling & layout

JavaScript (Vanilla JS) – Functionality

Inspired by the original Spotify design and functionality.
